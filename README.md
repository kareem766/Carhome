# Carhome

منصة عربية وسيطة لتأجير السيارات طويل الأجل للشركات في مصر.

## التقنية
- React + Vite + TypeScript
- Tailwind CSS
- Supabase (Auth, PostgreSQL, Storage, RLS)
- Vercel
- Arabic RTL + Cairo font + PWA

## الحالة
المرحلة 1.1: تأسيس المشروع. لا توجد جداول بيانات أو سياسات RLS مطبقة حتى الآن.

## التشغيل محليًا
```bash
npm install
npm run dev
```

أنشئ ملف `.env.local` من `.env.example` عند إعداد Supabase. لا تضع مفاتيح سرية في Git.
