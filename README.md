# Carhome

منصة عربية وسيطة لتأجير السيارات طويل الأجل للشركات في مصر.

## التقنية
- React + Vite + TypeScript
- Tailwind CSS
- Supabase (Auth, PostgreSQL, Storage, RLS)
- Vercel
- Arabic RTL + Cairo font + PWA

## الصفحات الرئيسية
- `/services` — خدمات السيارات: دليل خدمات الصيانة والتأمين وغيرها، مع البحث والتصفية حسب الفئة والمحافظة.
- `/automotive-services` — مسار بديل لصفحة خدمات السيارات.
- كتالوج السيارات ومساحات العمل حسب نوع الحساب.
- مسارات تسجيل مستقلة للشركات وموردي الأساطيل وملاك السيارات.

## ملاحظات النشر والبيانات
- معلومات مزودي الخدمات تُعرض كدليل استرشادي؛ ينبغي التأكد من العناوين والتغطية مباشرةً من مقدم الخدمة.
- لم تتطلب إضافة صفحة خدمات السيارات أي تغيير في قاعدة البيانات أو سياسات RLS.
- واجهة التحميل تستخدم شعار المنصة، مع تفضيل حركة هادئة واحترام إعداد تقليل الحركة.
- لا تضع مفاتيح سرية في Git؛ استخدم متغيرات البيئة المناسبة.

## التشغيل محليًا
```bash
npm install
npm run dev
```

أنشئ ملف `.env.local` من `.env.example` عند إعداد Supabase.
